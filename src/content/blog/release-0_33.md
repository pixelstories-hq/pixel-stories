Hey everyone! Update 0.33 is here, and the biggest part of this update is a major overhaul to the dialogue editor!

The dialogue editor now uses a proper code editor, which makes writing and editing dialogue a lot smoother and less buggy. Commands have much better autocomplete, can be searched using multiple words, and show helpful tooltips while you're selecting the command'. There are some new styling options too. Dialogue now supports Markdown-style **bold**, _italics_, and comments.

Along with that, you can now also run actions within the dialogue itself! This is useful for controlling the world while the dialogue is still opening.

This update also adds video assets! Videos can be played during events, repositioned and resized, have their properties changed, and be removed when you are done with them. Image actions got some improvements alongside this, including a rotate handle, a better game window preview, and fade in/out transitions.

Hope you enjoy the update!

## 0.33 key changes

- Rebuilt the dialogue source input with a smoother and more reliable editing experience.
- Added inline commands for running actions, showing variables, changing dialogue speed, and automatic pagination.
- Added improved command autocomplete, tooltips, reference badges, and automatic brace handling.
- Added Markdown-style bold, italics, and comments to dialogue.
- Added video assets and actions to play, edit, and remove videos.
- Added image rotation, improved resize controls, aspect ratio previews, and fade transitions.
- Added `else if` branches to conditional actions.
- Added scaling for NPCs and map objects.
- Redesigned the action picker and greatly improved action search.
- Added more safeguards against action data being lost during editing operations.
