Hey everyone!

Update 1.3 brings controller support and localization to PS Maker!

All PS Maker games now automatically get controller and Steam deck support! By default, there will be controller keybinds assigned to actions such as moving the player, interacting on triggers, and navigating menus. The event trigger label now has variants for keyboard and controller. The variant it displays depends on the device the player last used.

You can now translate your game into multiple languages, making it easier and more accessible for people to play your game! The new Localization page automatically surfaces any game text to translate, including dialogue, UI menus, NPC names, etc. You can translate directly in PS Maker, or export a CSV to use with translators or translation software, then import the completed translation. I also wrote a guide for [how you can localize your game](/localization/).

There are also a number of QoL features and bug fixes as usual. Full changelog is below. Hope you enjoy this update!
